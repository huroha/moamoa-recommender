# 모아모아 배치 추천기

메이플스토리 미니게임 「한글 모아모아」(가로 10 × 세로 16)에서 게임판과 보유 조각 3개를 입력하면, 놓을 순서·회전/반전·위치를 추천합니다.

**바로 쓰기: https://huroha.github.io/moamoa-recommender/**

## 사용법

1. 칸을 누르거나 끌어서 지금 게임판과 똑같이 채웁니다. 「능력 아이콘」 모드에서는 아이콘이 있는 칸을 찍습니다.
2. 보유 조각 3개를 고르고 「추천 받기」를 누릅니다.
3. 추천대로 놓은 뒤 「판에 적용」을 누르고 다음 조각을 고릅니다.

- **고득점 모드(기본)**: 다음 턴에 나올 조각까지 가정해 보고 고릅니다 (1~3초).
- **빠른 계산 모드**: 이번 조각만 보고 바로 고릅니다.

입력한 판은 브라우저에 저장됩니다. 서버 없이 브라우저 안에서만 계산합니다.

## 파일

- `index.html` — 화면
- `solver.js` — 추천 엔진 (빔 서치 + 다음 턴 내다보기)

비공식 팬 제작 도구이며 넥슨/메이플스토리와 관련이 없습니다.
